# Clash Tools Hub — Free static MVP

Independent, unofficial Clash of Clans fan toolkit. Static, mobile-responsive HTML/CSS/JS; no dependencies or build step.

## Included
- Four language selectors (English, Turkish, Spanish, Portuguese; English fallback for untranslated strings)
- Clan tag validation and opening an in-game clan profile
- Local-only saved base layout links (not a public gallery)
- Starter attack strategy tips
- Editable simplified upgrade calculator with local browser persistence

## Not yet included
- Live Supercell API statistics (requires a server-side integration and approved API key)
- Verified, public base layout catalog
- Up-to-date official upgrade values
- Full professional translations for Spanish and Portuguese
- Accounts, analytics, advertisements

## Free deploy with Cloudflare Pages
1. Open https://dash.cloudflare.com/ and sign up / sign in.
2. Go to Workers & Pages > Create > Pages > Upload assets (labels may change).
3. Upload the folder or the provided ZIP, and choose a unique project name.
4. Your site will get a free `your-project.pages.dev` address after deployment.
5. Test all sections on desktop and mobile.

No secrets/API keys should ever be put in `index.html`.
